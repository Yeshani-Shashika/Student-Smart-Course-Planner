# AcademicPilot – Career Path Recommendation System

AcademicPilot is a web-based Career Path Recommendation System designed to help users discover suitable career paths based on their skills, interests, and educational background. The platform provides personalized career recommendations through an interactive and user-friendly interface. Built using React, Next.js, Node.js, Express.js, and MongoDB, the system follows a modern three-tier architecture for scalability, maintainability, and performance.

## Features

* User registration and secure authentication
* Profile management and skill input
* Personalized career recommendation generation
* Admin dashboard for managing users and career data
* Responsive and modern UI design
* RESTful API integration
* MongoDB database management

## Technologies Used

* Frontend: React, Next.js
* Backend: Node.js, Express.js
* Database: MongoDB
* Tools: Visual Studio Code, Postman

## Project Goal

The main objective of AcademicPilot is to make career guidance more accessible, efficient, and technology-driven by providing users with personalized career recommendations through a responsive web application.

## Future Enhancements
